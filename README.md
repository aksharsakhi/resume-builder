# ⭐ Astra Resume Builder

A modern, ATS-ready resume builder with professional templates and export capabilities.

## Features

- **6 Professional Templates**: Professional, Modern, Creative, Minimal, Executive, Elegant
- **ATS Checker**: Analyze your resume for ATS compatibility
- **Export Options**: Download as PDF or Word document
- **Live Preview**: Real-time preview of your resume
- **Responsive Design**: Works on desktop and mobile

## Tech Stack

- React 19 + TypeScript
- Vite 7
- TailwindCSS 4
- jsPDF + html2canvas (PDF export)
- docx (Word export)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
